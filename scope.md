# Scope definition sheet — Wazy MVP

## What the MVP does
One person, one job, one screen (a chat; WhatsApp is the target). The user texts a small commitment in their own words. Wazy confirms in one line, including when it will nudge. At that time it sends ONE nudge with two buttons: Done / Later. Each nudge's outcome is recorded: done, later, no reply within 24 h, or "stop". Tied to Guess 1 (proactive nudges are wanted, not naggy).

## What the MVP deliberately does NOT do
Google/Outlook sync · web app and sign-up · morning/evening/weekly summaries · recurring events · voice notes · photo attachments · conflict detection · focus blocks · batch rescheduling · tentative holds · personalities and bot names · admin dashboard · landing-page AI demo · payments/paywall.

## Rule for adding features later
We will only add a new feature if a real user does this: at least two of the test users TRY to do the missing thing in real use (e.g. two text a weekly-repeating commitment → recurring returns; two forward a calendar invite → calendar sync returns). Asking for it in conversation doesn't count.
